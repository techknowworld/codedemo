JulesCare on Azure

A pilot-sized Azure deployment of the logical architecture: an all-.NET stack, with a Blazor web client (and optional MAUI Blazor Hybrid mobile apps) over one modular monolith on Azure Container Apps, the AI orchestrator and MCP server in their own containers with their own identities, and every data service behind a private endpoint in Canada.

Why not AKS

The brief asks for the simplest design that fits the pilot. Container Apps gives revisions, KEDA scaling, VNet integration and managed identities without running a cluster. Revisit AKS if the workload count or operational control needs grow.

Azure SQL or PostgreSQL

Azure SQL is shown for its built-in ledger tables and the team's .NET background. PostgreSQL Flexible Server also supports RLS; it would need an application-level hash chain for the audit log.

Web first, mobile later

Ship the Blazor web client for the pilot and December beta. Keep UI in the shared Razor library so the MAUI apps can follow when reviewers want mobile approvals, likely near the April 2027 introduction.

Check before committing

Confirm that the chosen Azure OpenAI models and Content Safety features are available in Canada regions, and that data-residency terms suit the provider pilots.
